# Giới thiệu bản thân — Nguyễn Trần Đăng Quang

Website giới thiệu cá nhân được xây dựng bằng HTML, CSS và JavaScript thuần, tối ưu cho máy tính và điện thoại.

## Chạy website

Mở `index.html` trong trình duyệt.

## Xuất bản bằng GitHub Pages

Trong repository, mở **Settings → Pages**. Chọn **Deploy from a branch**, chọn nhánh `main` và thư mục `/(root)`, sau đó lưu. Khi GitHub Pages hoàn tất triển khai, trang web sẽ có tại:

https://ngtrdangquang-pn26.github.io/Gioithieubanthan/

## Nội dung

- Thông tin cá nhân, ngày sinh, cung hoàng đạo, lớp và trường.
- Giới thiệu về TP. Hồ Chí Minh và quê quán Ninh Bình.
- Thiết kế pastel, các hiệu ứng cuộn nhẹ và thanh tiến trình cuộn.
- Bố cục responsive, các thẻ thông tin đã được căn giữa.
